# Exercise Types

Military exercises exist on a spectrum from study to live field execution.

| Type | Description | Typical Use |
|---|---|---|
| **Study period / staff ride** | Paper-based or terrain walk-through; low resource | Concept familiarization, doctrine review |
| **Map exercise / table-top exercise (TTX)** | Map or model-based decision-making; no troops | Command-post training, staff coordination |
| **Tactical decision exercise / TDG** | Short timed decision vignettes; individual or small group | Leader judgment drills, PME blocks |
| **Command post exercise (CPX)** | Headquarters-focused; simulated or real staff | Staff procedures, C2 systems, decision-making |
| **Field training exercise (FTX)** | Live execution with troops and equipment | Tactical proficiency, combined arms integration |
| **Computer-assisted exercise (CAX)** | Virtual, constructive, or live simulation integration | Large-scale operations, joint/combined training |
| **Command field exercise (CFX)** | Hybrid CPX + limited live execution | Command and control under semi-realistic conditions |
