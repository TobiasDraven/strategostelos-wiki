# Commissioning and Initiation

The exercise design process begins when the authority responsible for training identifies a need and issues a commissioning instruction or exercise directive. This document defines:
- Exercise name and classification
- Purpose and type
- Aim and focus
- Training and exercise objectives
- Participating and supporting forces
- Timeframe and locations
- Key appointments
- Resource allocation and constraints

## Commissioning Instruction

The commissioning instruction serves as the tasking document that:
- Mandates the exercise
- Appoints an Exercise Director
- Demarcates the objectives of the exercise
- Provides the framework within which the exercise is to be designed
- Stipulates the timeline for development and execution

## Exercise Specification Meeting

Before an exercise is commissioned, the Officer Scheduling the Exercise conveys intent, guidelines, and objectives in a formal conference to the core planning group. This meeting:
- Identifies key requirements and objectives
- Serves as the framework for drafting the commissioning instruction or exercise directive
- Defines the authority for all subsequent planning sessions

## Initial Planning Conference

Once the concept has been developed, the Exercise Director issues an exercise warning order and convenes the Initial Planning Conference. The IPC:
- Presents the approved concept to the full planning group
- Creates decentralized work groups for detailed planning
- Begins the translation of concept into executable plans
