# Exercise Design Templates and Checklists

> *"A properly planned framework gives the narrative writer great freedom for artistic expression."*
> — Adapted from EXDESIGN Textbook

## Purpose

This page provides standardised templates and checklists for exercise design. These tools ensure consistency, completeness, and quality across the exercise design process.

---

## Exercise Design Checklist

A sequential checklist of key design tasks:

### Stage 1: Commissioning

- [ ] Exercise Specification Meeting held
- [ ] Commissioning Instruction / Exercise Directive issued
- [ ] Exercise Director appointed
- [ ] Budget and resources allocated
- [ ] Key appointments identified

### Stage 2: Design and Development

- [ ] Concept Development Conference (CDC) scheduled
- [ ] Final Integrated Objective List (FIOL) compiled
- [ ] FIOL validated and SMART-I compliant
- [ ] Main Events List (MEL) drafted
- [ ] Master Incident List (MIL) drafted
- [ ] Exercise Concept drafted
- [ ] Site reconnaissance conducted
- [ ] Exercise Concept approved by EXDIR

### Stage 3: Detailed Planning

- [ ] Initial Planning Conference (IPC) held
- [ ] Work groups established
- [ ] Injects drafted and validated
- [ ] Exercise Control Matrix (ECM) compiled
- [ ] Inject Control Sheets (ICS) completed
- [ ] Training and Evaluation Plan drafted
- [ ] Main Planning Conference (MPC) held
- [ ] Exercise Plan finalised
- [ ] Final Planning Conference (FPC) held
- [ ] Exercise Order signed and issued

### Stage 4: Execution

- [ ] Exercise Control Centre (ECC) established
- [ ] EXCON briefed and in position
- [ ] Safety briefing conducted
- [ ] Exercise commenced
- [ ] Interim AARs conducted
- [ ] Exercise concluded

### Stage 5: Post-Exercise

- [ ] Hot wash conducted
- [ ] Formal AAR conducted
- [ ] After Action Report submitted
- [ ] Lessons learned captured and integrated
- [ ] Exercise records archived

| | 2.2 | |

**Formatting rules:**
- Themes numbered sequentially (1, 2, 3...)
- Events numbered within themes (1.1, 1.2, 2.1...)
- Events stated crisply: one to five words
- Multiple objectives may be linked to a single event

## Inject Control Sheet (ICS) Template

| Field | Content |
|-------|---------|
| **Inject Number** | e.g., 1.1.1-I1 |
| **Event / Incident** | Reference to MEL and MIL entries |
| **Date / Time** | Scheduled date and time |
| **Location** | Grid reference or named location |
| **Delivery Method** | Written, verbal, system input, AV, live |
| **PTA Element** | Specific PTA unit or headquarters receiving inject |
| **OPFOR Element** | OPFOR unit involved (if applicable) |
| **Controller** | Named controller responsible for delivery |
| **Inject Text** | Full text of the inject |
| **Expected Response** | What the PTA should do |
| **Assessment Criteria** | How the response will be evaluated |
| **Safety Considerations** | Safety risks and control measures |
| **Contingency** | What to do if PTA does not respond as expected |
| **Status** | Planned / In Progress / Complete / Cancelled / Modified |

## Quality Criteria Checklist

### MEL Quality Criteria

- [ ] Addresses every objective in the FIOL at least once
- [ ] Contains no events that cannot be traced to an objective
- [ ] Is sequenced in a logically coherent operational flow
- [ ] Is realistic given available time, space, and forces

### MIL Quality Criteria

- [ ] Deconstructs every MEL event into at least one incident
- [ ] Contains no incidents that cannot be traced to an event and objective
- [ ] Provides incidents that collectively stress every objective in the FIOL
- [ ] Is realistic given the operational context and PTA capabilities

### Inject Quality Criteria

- [ ] Contains all fields in the ICS format
- [ ] Inject text is clear, concise, and sufficient
- [ ] Assessment criteria linked to specific FIOL objectives
- [ ] Safety considerations address real risks
- [ ] Contingency options for common PTA failure modes

### Exercise Concept Quality Criteria

- [ ] Integrates MEL and MIL into a coherent operational narrative
- [ ] Includes timelines, locations, safety considerations, and control arrangements
- [ ] Has been presented to and approved by the EXDIR
- [ ] Is realistic given available resources and constraints
