# Inject Control Sheets — ICS

> *"The ICS is the detailed planning document for each individual inject. It provides the controller with all information required to execute the inject correctly."*
> — Adapted from EXDESIGN Textbook, Chapter 7

## What Is the ICS?

The **Inject Control Sheet (ICS)** is the detailed planning document for each individual inject. It provides the controller with all information required to execute the inject correctly: timing, delivery method, PTA element, expected response, assessment criteria, safety considerations, and contingency options.

**Critical rule:** The ICS is an EXCON document. It is **never** shared with the PTA.

---

## ICS Format

| Field | Content |
|-------|---------|
| **Inject Number** | e.g., 1.1.1-I1 |
| **Event / Incident** | Reference to MEL and MIL entries |
| **Date / Time** | Scheduled date and time |
| **Location** | Grid reference or named location |
| **Delivery Method** | Written, verbal, system input, AV, live |
| **PTA Element** | Specific PTA unit or headquarters receiving inject |
| **OPFOR Element** | OPFOR unit involved (if applicable) |
| **Controller** | Named controller responsible for delivery |
| **Inject Text** | Full text of the inject |
| **Expected Response** | What the PTA should do |
| **Assessment Criteria** | How the response will be evaluated |
| **Safety Considerations** | Safety risks and control measures |
| **Contingency** | What to do if PTA does not respond as expected |
| **Status** | Planned / In Progress / Complete / Cancelled / Modified |

---

## Quality Criteria

A well-constructed ICS:

- ✅ Contains all fields in the format above
- ✅ Has inject text that is clear, concise, and sufficient
- ✅ Has assessment criteria linked to specific FIOL objectives
- ✅ Has safety considerations that address real risks
- ✅ Has contingency options for common PTA failure modes
