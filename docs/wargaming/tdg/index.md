# Tactical Decision Games (TDGs)

> *"A tactical decision game is a short, focused exercise in which a commander or leader must make a decision under time pressure, based on a sparse situation and a sketch map — then explain the reasoning."*
>
> — adapted from USMC schoolhouse practice, transposed to SANDF command-post training

## What is a TDG?

A Tactical Decision Game is a **decision-forcing vignette**. It is not a planning exercise, not a battle simulation, and not a free Kriegspiel. Its purpose is singular: **compress the observe-orient-decide-act loop into a two-to-five-minute decision box**, then expose the reasoning to peer or umpire critique.

| Dimension | TDG | Command Post EX (CPX) | Field EX (FTX) |
|---|---|---|---|
| Time per decision | 2–5 min | 30–120 min | Hours to days |
| Fidelity | Sketch + narrative | Semi-structured | Full terrain |
| Audience | Section to Company | HQ to Bde | Battalion+ |
| Purpose | Judgment drill | Staff coordination | Live validation |
| Replayability | High — rerun with variants | Medium | Low — terrain-specific |

## SANDF TDG Format

Every TDG in this library follows the same minimal envelope so it can be run in a classroom, on a mapsheet, or over a sand table in 15 minutes flat.

### Structure

1. **Situation** — 3–8 sentences. Who, what, where, when, why. No solution embedded.
2. **Map Sketch** — North arrow, scale bar, key terrain labels, unit positions at H-hour. One-page maximum.
3. **Forces** — Friendly and enemy ORBAT in SANDF shorthand (unit type, weapons, key attachments).
4. **Constraints / Higher Guidance** — Mission, commander’s intent, ROE, logistical limits.
5. **Decision Required** — Single verb: *deploy*, *attack*, *delay*, *withdraw*, *report*, *request*. Timed.
6. **Decision Box** — Trainee writes: **(a) decision, (b) rationale in two sentences, (c) branches**.
7. **Umpire / Facilitator Notes** — Minimum acceptable standard, likely errors, inject variants.

### ORBAT Notation (SANDF Shorthand)

Use this throughout the library so every page is readable across units.

| Code | Meaning |
|---|---|
| Inf Sec | Infantry section (~12–15) |
| Inf Plt | Infantry platoon (~30–40) |
| Mech Plt | Mechanised platoon (Ratel-20/-25) |
| Mot Plt | Motorised platoon (Samil 50/100) |
| Arty Bty | Artillery battery (GV4/L22) |
| Tk Sqn | Tank squadron (Olifant/Rooikat) |
| Engr Sqn | Engineer squadron |
| Sig Sqn | Signals squadron |
| ADA Tp | Air Defence troop |
| Med Coy | Medical company |

### Adjudication Rubric

| Criterion | Pass (2) | Marginal (1) | Fail (0) |
|---|---|---|---|
| **Decision aligns with mission/ intent** | Directly supports higher intent | Partially supports | Contradicts |
| **Terrain used** | Key terrain seized/denied | Terrain mentioned | Terrain ignored |
| **Force protection** | Survivability considered | Partial | Reckless |
| **Tempo / surprise** | Timing creates advantage | No consideration | Inverted |
| **Branch awareness** | Next 2–3 moves named | One branch named | None |
| **ROE / legal** | Compliant | Borderline | Breach noted |

Score ≥ 8/12 = **ACCEPT**. 5–7 = **REDO with facilitator**. ≤4 = **FAIL — retrain before independent command**.

## How to Use This Library

1. Select the echelon matching your training event.
2. Print the TDG + map sketch; distribute one copy per trainee.
3. State the decision box aloud, start the timer.
4. Collect at time; read anonymously or call on trainees.
5. Run the Umpire Notes; score against the rubric.
6. Re-run with **inject variant** (see page footer) to test flexibility.
