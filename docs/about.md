# About

## Purpose

Strategos Telos is a curated knowledge base for military theory, wargaming, scenario design, and strategic analysis.

## Scope

- Conventional military theory and doctrine
- Wargaming and CONSIM methodology
- Scenario design and exercise planning
- Strategic analysis frameworks
- Research notes and working papers

## Governance

This wiki is maintained by direct curation. There is no crowdsourced editing. Every page is authored, reviewed, and deployed by a single curator with full accountability.

## Citation Standard

All substantive claims must cite their source. No unattributed assertions.

## Platform

Built with MkDocs Material, deployed via GitHub Pages. Content is stored as plain-text markdown in version control.
