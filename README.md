# Strategos Telos Wiki

Curated knowledge base for military theory, wargaming, and strategic analysis.

Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/). Deployed via GitHub Pages.

## Local Development

```bash
python3.12 -m mkdocs serve
```

Open http://localhost:8000

## Deploy

```bash
python3.12 -m mkdocs gh-deploy
```
